# Техническое задание
Разработать веб-инструмент для просмотра и разметки текстовых датасетов, обладающий следующей функциональностью:

### Страница со списком датасетов
- Загрузка датасета (в формате CSV);
- Переименование и удаление датасета;
- Сортировка и фильтрация по названию;
- Выгрузка размеченных датасетов в форматах CSV и JSON.

### Страница работы с датасетом
- Вкладка разметки
  - Постраничный просмотр датасета;
  - Разметка строк;
  - Создание, переименование, удаление, сортировка, фильтрация меток.
- Вкладка поиска
  - Поиск по запросу;
  - Постраничный просмотр результатов поиска.

# Технологический стек
Backend: 
- Java
- Spring Framework (Boot, Web, JPA)
- PostgreSQL, Hibernate, Flyway 
- ElasticSearch
- Apache Commons CSV

Frontend:
- JavaScript
- Vue.js 3
- Vuetify
